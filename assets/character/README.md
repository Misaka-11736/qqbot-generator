# 角色素材说明

这里的立绘来自项目作者提供的角色设定图（三视图），**不随本项目的 MIT 许可授权**。如果你要分发本项目，请确认你拥有该素材的使用权，或替换成自己的立绘。

| 文件 | 内容 |
| --- | --- |
| `character.png` | 正面立绘，透明背景，720px 高 |
| `avatar.png` | 圆形头像，320×320，浅蓝底 |

## 怎么生成的

`scripts/make_character.py`：

1. 从原图裁出正面视图；
2. 从四边泛洪填充去掉白底（角色内部的白色蕾丝/围裙保留）；
3. 边缘 alpha 轻微模糊，减少锯齿；
4. 生成头像时裁脸部区域并套圆形蒙版，垫一层浅蓝底。

换素材时，把新的正面立绘放进这个目录，保持文件名即可；`mascot.py` 会按高度自适应。

## 配色

界面的海军蓝 `#14224A`→`#2C4E92`、天空蓝 `#4F7FE0`、蕾丝白、圆角扇形装饰，都取自这张设定图。
