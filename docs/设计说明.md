# 设计说明

## 参考

界面按项目作者提供的角色设定图重做：蓝发、鲸鱼鳍耳、女仆头饰、深海军蓝连衣裙、白色蕾丝围裙（围裙上还有一只小蓝鲸）。

由此提炼出三个关键词：

- **海军蓝**：主色从原来的珊瑚橙换成 `#14224A → #2C4E92` 的深蓝渐变；
- **蕾丝白**：卡片、按钮文字、围裙式的大面积留白；
- **圆润**：圆角、扇形花边、胖乎乎的立绘。

角色在界面里叫「小鲸」，定位是「住在 QQ 里的蓝鲸女仆」。

## 配色

| 角色 | 颜色 | 用途 |
| --- | --- | --- |
| 深海 | `#0E1830` | 侧栏 |
| 海军蓝 | `#14224A` → `#2C4E92` | 首页 Hero 渐变 |
| 天空蓝 | `#4F7FE0` | 主按钮、选中态、强调 |
| 浅蓝 | `#E1EBFF` | 选中底、标签底 |
| 雾蓝 | `#F3F7FF` | 页面底色 |
| 蕾丝白 | `#FFFFFF` | 卡片 |
| 墨色 | `#1A2340` | 标题 |

状态色只用于胶囊：成功 `#35B98A`、警告 `#F0B459`、错误 `#E25C6A`。

## 布局

- 左侧 236px 深蓝导航，底部用两排扇形蕾丝收边；
- 顶部 96px：页面标题 + 三个状态胶囊 + 全局启动按钮；
- 首页 Hero 是深蓝渐变卡片，左侧文案、右侧立绘，白色主按钮；
- 其余页面为白色圆角卡片流，固定底栏放保存/测试；
- 聊天和日志页撑满剩余高度。

## 角色资源

立绘由作者提供，透明背景版本由 `scripts/make_character.py` 从三视图里抠出：

- `assets/character/character.png`：720px 高的正面立绘；
- `assets/character/avatar.png`：圆形头像，用于侧栏和聊天气泡。

渲染时按控件高度等比缩放，带 4px 的上下浮动和气泡粒子；没有资源时退化成蓝底「鲸」字圆，不会崩。

> 这套立绘**不随 MIT 授权**，详见 `assets/character/README.md`。

## 交互细节

- 主按钮统一蓝渐变，深色背景上用白底按钮保证对比度；
- 状态胶囊同时有颜色和文字，不只靠颜色区分；
- 保存、测试、下载都有 Toast 或行内反馈；
- 关闭窗口时如果机器人还在跑，询问「最小化到托盘 / 退出并停止」；
- 模型测试、人格试一句、NapCat 下载都在后台线程，界面不卡。

## 还差什么

- 深色模式（颜色集中在 `theme.py`，加一套 token 即可）；
- 更多表情差分（现在只有一张正面）；
- 页面切换过渡动画；
- 角色立绘在 2K/4K 下的 2x 资源。
