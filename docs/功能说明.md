# 功能说明

## 首页

- **启动 / 停止机器人**：用子进程拉起内核，状态实时刷新；
- **三张状态卡**：机器人（PID、运行时长、端口）、模型（当前模型或离线）、NapCat（是否找到、路径）；
- **快速入口**：配置 NapCat 连接、打开 WebUI、跑自检、打开数据目录；
- **最近日志**：最近 6 行，点「查看全部」去日志页。

## 机器人

| 配置 | 说明 |
| --- | --- |
| 机器人名字 | 进提示词，也用于自称 |
| 管理员 QQ | 你本人的号；群里只有管理员能执行 `/reset` |
| 作用域·私聊 | 是否响应私聊，关闭后私聊完全不理 |
| 作用域·群聊 | 是否响应群聊，关闭后群消息直接丢弃 |
| 群范围 | 所有群 / 仅白名单 / 排除黑名单 |
| 群号列表 | 白名单或黑名单的群号，逗号/空格/顿号分隔 |
| 忽略的用户 | 这些 QQ 说什么都不回 |
| 模式 | 反向（NapCat 连机器人）/ 正向（机器人连 NapCat） |
| 主机 / 端口 / 路径 | 默认 `127.0.0.1:3002/onebot/v11/ws` |
| Token | 与 NapCat 一致，本机自用可空 |
| 搭话概率 | 群里没被 @ 时插话的概率，0 表示只在被叫时说话 |
| 搭话冷却 | 同群两次主动说话的最小间隔 |
| 上下文轮数 | 带多少轮历史给模型，越大越贵 |
| 每人限流 | 每分钟最多触发次数 |
| 单条最长 | 超过会拆段或截断 |
| 模拟打字延迟 / 引用回复 | 更像真人的两个小开关 |

底部「保存配置」写入 `config.toml`；「保存并重启」会在机器人运行时自动重启。

## 模型

- **只负责文字聊天 Provider**：DeepSeek / Qwen / SiliconFlow / OpenRouter / OpenAI / Groq / 智谱 / 本地 Ollama；
- 选择 Provider 自动填接口地址和聊天模型，也可以手动改模型名；
- 调用方式：自动 / 强制在线 / 强制离线；
- 接口地址：填到 `/v1` 为止，程序自动补 `/chat/completions`；
- API Key：DPAPI 加密存 `secrets.json`，不写进 `config.toml`；
- 温度、最大生成长度、超时；
- 底部「测试连接」会真的发一句话，返回耗时和翻译后的错误原因。

## 能力

- **聊天 Provider 只读**：在模型页修改；
- **看图 Provider**：默认跟随聊天；可单独选 Qwen/OpenAI/SiliconFlow/OpenRouter/智谱/Ollama，并填独立 Key；
- **语音识别**：本地 faster-whisper，或 OpenAI/Groq/SiliconFlow 的 `/audio/transcriptions`；
- **语音合成**：本地 Edge-TTS，或 OpenAI/Groq/SiliconFlow 的 `/audio/speech`；
- **搜索**：Brave / Tavily / DuckDuckGo；
- 能力开关按选定 Provider 是否支持自动启用/禁用；
- 云端语音失败直接报错，不静默回退本地；
- 新用户默认只开聊天与归档，其余能力关闭；
- **群聊社交影子模式**：只记录“本来会不会接话”和群话题，不发送、不改现有回复；摘要频率、空闲补摘要、保留 1–7 天、100 MB 上限均可配置。

## 人格

- 三套预设：损友 / 软妹 / 学霸，点击切换编辑对象；
- 智商滑杆 1~200，实时显示档位和该档位的行为描述；
- 人格编辑器：Markdown，`{bot_name}` 会替换成机器人名字；
- 「恢复默认」从安装包里的原文恢复；
- 「保存人格」写到 `%LOCALAPPDATA%\QQBotGenerator\prompts\<preset>.md`，新消息立即生效；
- 底部「试一句」：有 Key 走真模型，没 Key 走离线大脑。

## NapCat

- 自动检测常见位置：数据目录、`D:\QQ Bot\NapCat\app`、`NapCat*Shell*`；
- 浏览手动选择（认 `launcher.bat` 或 `napcat.bat`）；
- 配置连接：写入 `config\onebot11.json` 和 `webui.json`（端口 6099，token `qqbot-local-2026`）；
- 启动 NapCat：ShellExecute 提权运行，UAC 需要你点「是」；
- 打开 WebUI：`http://127.0.0.1:6099/webui/?token=...`；
- 下载 NapCat：从 GitHub Releases 拉 v4.18.38 Shell 包，解压到数据目录。

## 试聊

- 独立会话，记忆在 `chat_memory.json`；
- 群聊只保留 `/reset`（管理员），其他斜杠按普通聊天；智商与风格从「人格」页实时生效；
- 修改配置后会自动重建会话；
- 「清空对话」只清本地试聊记忆。

## 日志

- 跟随 `logs/bot.log`，文件变化即刷新；
- 自动滚动可关；支持打开日志目录；
- 清空只清界面，不动文件。

## 评审与自动迭代

- 每次 Bot 启动时检查有没有新的人工标注；没有新标注直接跳过，不调用模型；
- 同类原因（逻辑/语气/长度/时机/事实/重复）至少 5 条才生成规则；
- 低风险规则（语气、长度、时机、重复）自动生效，写入 system prompt 的“近期适应”区块；
- 高风险规则（逻辑、事实、人格、群规则）进入「评审」页待确认；
- 规则存 `rules.json`，带版本、证据、TTL、作用域，可单条停用或回滚；
- 规则同类别覆盖，最多保留 20 条，避免互相矛盾。

## 诊断

- 启动 2.5 秒后自动检查一次，发现问题只提示，不弹大窗；
- 检查项：数据目录、QQ 版本、NapCat 目录、loadNapCat.js、OneBot 端口、文字 Provider、能力 Key、最近日志；
- 安全项自动处理（目录创建、配置迁移、缓存清理）；
- 涉及 QQ 文件的修复只给按钮：`loadNapCat.js` 复制需要 UAC；
- 不自动重启 QQ，不自动切换 Provider，不自动回退离线；
- 版本不匹配显示“下载匹配版本”，未知版本不自动安装。

## 设置

- **环境自检**：数据目录、配置、人格、提示词、消息解析、智商档位、离线大脑、端口、NapCat，共 9 项；
- **数据与配置**：打开目录、导出/导入 `config.toml`、清空聊天记忆；
- **开机自启**：写 `HKCU\...\Run`，只启动界面，不自动登录 QQ；
- **恢复默认配置**：删除并重建 `config.toml`。

- 双击图标恢复窗口；
