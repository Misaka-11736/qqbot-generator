# 常见问题

## 安装与启动

**双击没反应 / 闪过一个窗口就没了**

用命令行跑一次，能看到退出码：

```powershell
& "$env:LOCALAPPDATA\Programs\QQBotGenerator\QQ Bot生成器.exe"
```

如果是杀软拦截，先把安装目录加入白名单。未签名的 PyInstaller 包被误报很常见，可以自己从源码打包验证。

**SmartScreen 拦截**

点「更多信息 → 仍要运行」。介意的话自己签个名，见 [打包与发布](打包与发布.md)。

**忘了装在哪**

开始菜单搜「QQ Bot生成器」；或看注册表：

```powershell
Get-ItemProperty "HKCU:\Software\Microsoft\Windows\CurrentVersion\Uninstall\QQBotGenerator"
```

**卸载后配置还在？**

故意的。卸载只删程序，`%LOCALAPPDATA%\QQBotGenerator` 里的配置、记忆、NapCat 都保留。要彻底清理手动删这个目录。

## 机器人

**点启动没反应，或状态一直「启动中」**

- 看日志页最后几行；
- 端口被占：机器人页换一个端口（记得同步 NapCat 里的地址）；
- 杀软拦截了 exe 起子进程。

**日志出现 `端口 3002 监听失败`**

另一个机器人实例还在跑，任务管理器结束它，或换端口。

**NapCat 已连，但私聊不回**

- 日志有没有 `登录账号`；
- 模型是不是 401/402（看日志）；
- 每人每分钟限 8 次，等一分钟；
- 群里发过 `/闭嘴` 就发 `/开口`。

**群里 @ 了还是不回**

确认 @ 的是机器人登录的小号；QQ 的「@」在转发时可能变成昵称文本，必要时在句首加 `/` 触发指令测试。

## NapCat

**WebUI 提示 network error**

NapCat 没起来，6099 没监听。先退出所有 QQ，再点「启动 NapCat」；10 秒后仍不行，用「显示窗口启动」看报错。

**WebUI 要的 Token 是什么**

初始登录密钥，在 `NapCat\app\config\webui.json`，默认 `qqbot-local-2026`；登录后设置的 WebUI 密码才是内置控制台要填的。

**提示「登录成功但没有拿到 token」**

旧版本的解析 bug（NapCat 返回字段是 `Credential`），升级到 2.1.0 即可。

**窗口右边/下边缩放区域特别大**

旧版本的自绘手柄和系统热区冲突，2.1.0 已改为 4px 手柄并屏蔽系统热区。


**自动检测不到**

NapCat 页点「浏览」，选到有 `launcher.bat`（Shell 版）或 `napcat.bat`（一键版）的那一层。

**启动 NapCat 一闪而过**

管理员身份开 cmd：

```powershell
cd /d "D:\QQ Bot\NapCat\app"
launcher.bat
```

报错会留在屏幕上。常见原因：找不到 QQ、QQ 版本不匹配、杀软拦截注入。

**提示「版本兼容性不佳」**

NapCat 按 QQ 9.9.22 打包，你装的是别的版本。能登录就先用；异常就换一键包（会装一个独立的 QQ）。

**扫码后 QQ 闪退**

关掉杀软实时防护重试；或换一键包；或换个小号。

**WebUI 打不开**

默认 6099，被占用时 NapCat 会自动 +1，看控制台打印的实际地址。token 在 `config\webui.json`，首次登录后会被强制改密码。

## 模型

**测试连接 401**

Key 错、过期、或复制时带了空格/换行。

**402**

余额不足。DeepSeek 需要先充值。

**404**

`base_url` 或模型名写错。多数服务商要带 `/v1`，智谱是 `/api/paas/v4`。

**超时**

换更快的模型；把超时调到 120 秒；本地 Ollama 首次加载模型会很慢。

**回复很短、像模板**

你可能在离线模式：模型页看「调用方式」和 Key，保存后重启机器人。

## 数据与隐私

**聊天记录在哪**

`%LOCALAPPDATA%\QQBotGenerator\memory.json`（正式）、`chat_memory.json`（试聊）。明文 JSON。

**怎么清空**

设置页「清空聊天记忆」，或群发 `/重置`。

**Key 会不会上传**

只存在本机 `config.toml`，请求时发给模型厂商。不会发给本项目作者。

## 其他

**支持 Windows 10 吗**

初版只测了 Win11。Win10 理论上能跑（Qt6 支持），但 NapCat 和界面都没验证，遇到问题请提 issue。

**能多开吗**

可以，但每个实例要不同端口、不同数据目录（`QQBOT_DATA_DIR`），NapCat 也要多开。普通用户不建议。

**界面太糊 / 太小**

Qt6 默认跟随系统缩放。高分屏可以在 exe 属性 → 兼容性 → 更改高 DPI 设置里调。
