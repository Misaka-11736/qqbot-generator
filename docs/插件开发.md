# 插件开发

## 目录

用户插件放在数据目录：

```text
%LOCALAPPDATA%\QQBotGenerator\plugins\<name>\
  plugin.json
  main.py
  config.json   （可选）
```

## plugin.json

```json
{"name":"hello","version":"1.0.0","description":"示例","author":"你"}
```

## main.py

```python
async def handle(ctx):
    if "插件测试" in ctx.text:
        await ctx.reply("插件系统已就位。")
        return True
    return False
```

返回 True 表示这条消息已被插件消费，机器人不再走默认回复。

## ctx 可用

- `ctx.text`：消息文本
- `ctx.incoming`：原始消息对象
- `await ctx.reply(text)`：发文字
- `await ctx.image(path, caption)`：发图片
- `await ctx.voice(path)`：发语音
- `await ctx.search(query)`：调用搜索

## 开关

`plugins.json`：

```json
{"hello": true}
```

## 注意

插件以 Python 代码在本进程运行，**只安装你信任的插件**；插件异常会被捕获，不会拖垮机器人。
