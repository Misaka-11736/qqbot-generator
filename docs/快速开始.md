# 快速开始

## 1. 安装

下载 `QQ Bot生成器-安装包.exe`，双击，下一步到底。

- 按用户安装，**不需要管理员权限**；
- 默认位置 `%LOCALAPPDATA%\Programs\QQBotGenerator`；
- 想装到别处，在安装向导里改目录即可（比如 `D:\QQ Bot\GUI App`）。

首次运行时 Windows 可能弹 SmartScreen（未签名应用的正常现象），点「更多信息 → 仍要运行」。

## 2. 第一次打开

界面左边是导航，右边是内容。第一件事去 **模型页**：

| 文字 Provider | 接口地址 | 默认模型 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| Qwen / 百炼 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| SiliconFlow | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-72B-Instruct` |
| OpenRouter | `https://openrouter.ai/api/v1` | `openai/gpt-4o-mini` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| Groq | `https://api.groq.com/openai/v1` | `llama-3.3-70b-versatile` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |
| 本地 Ollama | `http://127.0.0.1:11434/v1` | `llama3.1` |

在模型页选「文字 Provider」，地址和模型会自动填；粘贴 Key 后点 **测试连接**，绿色「连通」再保存。模型页只管聊天，看图/语音/搜索去 **能力页** 配。

> 没有 Key 也能继续：默认走离线大脑。新用户只开聊天与归档，能力默认关闭。

配完模型后，去 **能力页** 看需要什么：

- 看图：默认跟随聊天；聊天 Provider 不支持视觉时，单独选 Qwen 等并填 Key；
- 语音识别/合成：默认本地 Whisper / Edge-TTS，也可以选 OpenAI/Groq/SiliconFlow；
- 搜索：Brave / Tavily / DuckDuckGo；
- 不需要的能力保持关闭即可。

## 3. 准备 NapCat

NapCat 是 QQ 和机器人之间的中间人。两种方式：

**A. 机器上已经装过**：到 **NapCat 页** 点「自动检测」，选中 `launcher.bat` 所在目录。

**B. 没装过**：在 NapCat 页点「下载 NapCat（约 36 MB）」，它会下载到 `%LOCALAPPDATA%\QQBotGenerator\napcat` 并自动解压、写好连接配置。

下载完成后点 **配置连接**，把 OneBot 地址写进 NapCat 的 `config\onebot11.json`。

## 4. 启动 NapCat 并登录

1. 回首页点 **启动机器人**（先让它监听 3002 端口）；
2. NapCat 页点 **启动 NapCat** → UAC 点「是」→ 会弹出 NapCat 控制台和 QQ 登录窗口；
3. 手机 QQ 切到**小号**，扫 QQ 窗口的二维码；
4. 第一次进 WebUI 会用 Token 登录：
   - Token 在 `NapCat\app\config\webui.json`，默认 `qqbot-local-2026`；
   - 登录后按提示设置一个**WebUI 密码**，这个密码才是软件「内置控制台」要填的；
5. 登录成功会看到：

```
INFO    NapCat 已接入：('127.0.0.1', 52341)
INFO    登录账号：你的小号昵称（123456789）
```

顶部状态变成「机器人运行中」+「NapCat 已连」，就通了。

## 5. 验收

用你的大号私聊小号：

| 发送 | 预期 |
| --- | --- |
| 在吗 | 几秒内回复 |
| `搜张丑猫发来` | 识别为图片任务：搜图→下载→发图 |
| 我在设置里给你智商调低了 | 「怪不得我现在看你都觉得顺眼了。😊」 |
| 拉进群，@ 小号 | 有回复；不 @ 时大概率不理 |

## 6. 接着可以做的

- **机器人页**：改名字、填管理员 QQ、调搭话概率；
- **人格页**：改人设、拖智商滑杆；
- **试聊页**：不登录 QQ 先试效果；
- **设置页**：跑自检、导出配置、开机自启；
- 关闭窗口时选择「最小化到托盘」，它会继续在后台跑。

## 遇到问题

先看 **日志页**，再看 [常见问题](常见问题.md)。

三个快速自检入口：

1. 设置页 → 环境自检（9 项）；
2. 日志页 → 有没有 `NapCat 已接入`；
3. 试聊页 → 能不能回话（验证模型，不依赖 QQ）。
