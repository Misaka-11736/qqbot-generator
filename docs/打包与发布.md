# 打包与发布

## 环境

- Windows 11 x64
- Python 3.11+（推荐 3.12）
- NSIS 3（生成安装包）

```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt -r requirements-build.txt
```

## 一条命令

```powershell
powershell -ExecutionPolicy Bypass -File installer\build_installer.ps1 -Nsis "C:\Program Files (x86)\NSIS"
```

脚本依次做：

1. `scripts/make_assets.py` 生成箭头/勾选小图；
2. `scripts/make_icon.py` 离屏渲染吉祥物，生成 `assets/icon.png` / `icon.ico`；
3. `pyinstaller --clean qqbot-generator.spec`；
4. 把 `dist\QQBotGenerator.exe` 改名为 `dist\QQ Bot生成器.exe`；
5. `makensis installer\qqbot-generator.nsi`。

产物：

| 文件 | 说明 |
| --- | --- |
| `dist\QQ Bot生成器.exe` | 单文件绿色版，约 47 MB |
| `dist\QQ Bot生成器-安装包.exe` | NSIS 安装包，按用户安装 |

## 手动分步

```powershell
python scripts\make_assets.py
python scripts\make_icon.py
python -m PyInstaller --noconfirm --clean qqbot-generator.spec
move dist\QQBotGenerator.exe "dist\QQ Bot生成器.exe"
makensis /INPUTCHARSET UTF8 installer\qqbot-generator.nsi
```

> `.nsi` 是 UTF-8 无 BOM，必须加 `/INPUTCHARSET UTF8`，否则会报 `Bad text encoding`。

## spec 里做了什么

- `datas` 把 `qqbot_core/prompts` 和 `assets` 带进包；
- `excludes` 去掉 tkinter、numpy、PIL、setuptools 等用不到的东西；
- `console=False`：双击不弹黑窗口；
- `icon` / `version`：任务栏图标和文件属性；
- 单文件模式（EXE 直接带 binaries + datas）。

## 安装包行为

- `RequestExecutionLevel user`：按用户安装，不触发 UAC；
- 默认目录 `%LOCALAPPDATA%\Programs\QQBotGenerator`；
- 开始菜单建文件夹；桌面快捷方式是可选项（默认不勾）；
- 写 HKCU 卸载项，控制面板可卸载；
- 卸载**不会**删 `%LOCALAPPDATA%\QQBotGenerator`（配置、记忆、NapCat 都留着）。

## 代码签名（可选）

未签名的 exe 会触发 SmartScreen。要正式分发，买一张代码签名证书，然后：

```powershell
signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 /a "dist\QQ Bot生成器.exe"
signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 /a "dist\QQ Bot生成器-安装包.exe"
```

先签 exe，再打安装包，最后签安装包。
